# アルファベットたまクイズ

ビリヤードのボールでアルファベットをおぼえよう。
A〜Z の文字入りビリヤードボールを使った、子ども向けアルファベット練習アプリです。

## 機能

- **ボール→もじ**：ビリヤードボールの文字を見て、読みかたを4択で選ぶ
- **もじ→ボール**：読みかたを見て、正しい文字のボールを4択で選ぶ
- **難易度**：やさしい（大文字のみ）／ふつう（大文字＋小文字）／むずかしい（小文字のみ）
- **ひとりでモード**：1セット10問、正解数とメッセージを最後に表示
- **しょうぶモード**：2プレイヤー・同一端末パス方式の Nせんしょうぶ（1・3・5ラウンド）
- 本物に近いビリヤードボールデザイン（ソリッド／ストライプ）の SVG ビジュアル
- PWA 対応（ホーム画面に追加してオフラインで遊べる）

## 開発コマンド

```bash
npm install       # 依存インストール
npm run dev       # 開発サーバー → http://localhost:5173/
npm run build     # 本番ビルド → dist/
npm run preview   # ビルド結果のローカル確認
```

## 技術スタック

- React 19 + Vite
- JavaScript (JSX)
- vite-plugin-pwa（PWA対応）
